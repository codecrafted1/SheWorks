# 👩‍💼 SheWorks – Women Empowerment Platform

SheWorks is a women-focused empowerment platform designed to provide safety, awareness, and access to government schemes. It helps women connect with essential resources like SOS emergency support, welfare schemes, and community assistance in one place.

The platform aims to promote safety, independence, and empowerment for women through technology.

---

## 🌟 Features

- 🚨 **SOS Emergency Alert System**  
  Instant emergency alert feature for quick assistance during unsafe situations.

- 🏛️ **Government Schemes Directory**  
  Access and explore women-related government schemes easily.

- 📍 **Safety Tools & Resources**  
  Safety guidelines, helplines, and support resources.

- 👩‍👩‍👧 **Community Support**  
  Connect with awareness programs and empowerment initiatives.

- 🔎 **Search & Filter Schemes**  
  Quickly find relevant schemes based on eligibility.

- 📱 **User-Friendly Dashboard**  
  Simple and accessible interface designed for all users.

---

## 🛠️ Tech Stack

- Frontend: React  
- Styling: CSS Modules  
- Backend: Node.js / Express 
- Database: MongoDB   
- Authentication: JWT
